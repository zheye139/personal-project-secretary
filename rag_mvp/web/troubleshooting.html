A. API service does not open

Start the local API in a PowerShell terminal:

.\run_api.ps1

Then open:

http://127.0.0.1:8000/
http://127.0.0.1:8000/docs

B. Search fails

  • keyword mode mainly depends on Qdrant and the current index.
  • vector and hybrid also depend on local Ollama embedding.
  • Open Diagnostics first to check local service status.

C. Ask fails

  • Ask depends on Qdrant, Ollama, and index state.
  • Ask may take longer than simple Search requests.
  • Current Web Ask does not save QA logs.
  • If Ask fails, check Diagnostics first.

D. Diagnostics shows Qdrant unavailable

Check whether the local Qdrant container is running:

docker ps

E. Diagnostics shows Ollama unavailable

Check whether local Ollama is available:

ollama list

F. Page returns 404

  • /api is the API overview.
  • /api/v1/... routes are API endpoints.
  • /docs is the FastAPI documentation.
  • /favicon.ico is not functionally important if a browser checks it.

G. Information that should not appear on pages

Web pages and API responses should not display:

  • Windows drive-letter absolute local paths
  • private knowledge-base absolute paths
  • config URLs
  • raw context
  • prompt
  • source path
  • raw payload
  • full Markdown text
  • stack traces
